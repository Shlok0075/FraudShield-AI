# ml/data/raw/

This folder contains the raw datasets used by the FraudShield ML pipeline:

- `creditcard.csv` — legacy credit-card benchmark (120,000 rows, synthetic, generated by `ml/src/generate_dataset.py`)
- `PS_20174392719_1491204439457_log.csv` — PaySim raw (6,362,620 rows, 493 MB) — **active training data for `ml/models/live-v1/`**

The active serving model (`ml/models/live-v1/`) is trained on PaySim point-in-time features
(`ml/data/processed/paysim-v1/`). The legacy credit-card model (`ml/models/model.joblib`) remains available
but is not the active serving model.

**To regenerate the credit-card dataset:**
```bash
cd ml
source ../backend/venv/bin/activate   # or your own venv with ml/requirements.txt installed
python src/generate_dataset.py
```

**To rebuild PaySim features from raw:**
```bash
cd ml/src
python -m fraudpipe.build_dataset --input ../data/raw/PS_20174392719_1491204439457_log.csv \
    --out ../data/processed/paysim-v1 --seed 42
```

**To retrain the live model on PaySim:**
```bash
python ml/src/train_live_paysim.py
```
